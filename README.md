Entry for the make.fun bounty [One Star, Five Stars for the Food](https://make.fun/c/u-po-pu-one-star-five-stars-for-the-food-f9166ee7): one sentence, at most 200 characters — an alien tourist's one-star review of Earth with a real compliment for the food.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

The program writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`, then reads it back and asserts the gate: 1–200 characters, not only whitespace, exactly one sentence. Stdlib only, no network, deterministic.
